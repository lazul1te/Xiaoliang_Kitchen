# 拿手菜小本本

好好做饭，也好好记录。

一个两个人一起记的菜谱小程序：像翻餐厅菜单一样挑今天要做的菜，每道菜记下原料和详细做法；做的时候一步一步看、带计时，做完打个卡。能打开这个小程序的人（管理员和体验成员）共用一本菜谱，都能看、都能改。原生小程序（JavaScript）+ 微信云开发（免费环境）。只用体验版，不发布上线。

## 第一次运行前

1. **建数据库集合**：开发者工具顶部点「云开发」打开控制台 → 数据库，新建四个集合 `categories`、`dishes`、`plans`、`cook_logs`。
2. **把权限设成两个人共用**：四个集合都打开权限设置，选「自定义安全规则」，把输入框里原来的内容全部删掉，换成：
   ```json
   {
     "read": "auth.openid != null",
     "write": "auth.openid != null"
   }
   ```
   意思是用微信打开这个小程序的人都能读写（体验版只有体验成员能打开）。`{ "read": true, "write": true }` 控制台会报 rule invalid，不能用。
   也不要选「仅创建者可读写」或「所有用户可读，仅创建者可写」：前者看不到对方的菜，后者改不了对方加的菜。
3. **部署照片用的云函数**：免费环境的云存储权限是「只有上传的人能读」，而且改不了（要升级付费版才能改），所以对方传的照片要靠云函数才看得到。在开发者工具左边的 `cloudfunctions` 里右键 `photo` 文件夹，选「上传并部署：云端安装依赖」，等它提示部署成功。以后改了 `cloudfunctions/photo` 里的代码也要这样重新部署一次。
   装好以后，「我的 → 检查云数据库」可以检查四个集合和照片。
4. **填环境 ID**（建议）：控制台里复制环境 ID，填进 `miniprogram/config.js`。不填的话会用账号下第一个创建的环境。
5. **隐私保护指引**：小程序后台 → 设置 → 服务内容声明 → 用户隐私保护指引，声明两项：
   - 「选中的照片或视频信息」，用途写「给菜品、做菜步骤和做菜记录添加照片」。不填的话选不了照片。
   - 「选中的文件」，用途写「导入菜谱数据文件」。不填的话「数据导入」选不了文件。
   - 「剪切板」，用途写「复制买菜清单；复制、粘贴菜谱数据（导入导出）」。不填的话复制、粘贴都用不了。
6. **加体验成员**：小程序后台 → 成员管理 → 体验成员，用微信号把对方加进来（个人小程序最多 15 人）。

## 发体验版（给手机上用）

1. 开发者工具右上角点「上传」，版本号写 `1.0.0` 这样的，备注随便写。
2. 打开小程序后台 → 管理 → 版本管理，在「开发版本」里把刚上传的版本「选为体验版」，就能看到体验版二维码。
3. 两个人用微信扫这个二维码打开；以后在微信下拉的「最近使用」里就能找到。
4. 以后每次改完代码，重复 1、2 两步，重新打开小程序就是新版本。
5. **千万别点「提交审核」或「发布」**：发布后免费云环境会在上线第 15 天到期，之后要付费。

## 两个人一起用

- 一方改了，另一方重新打开小程序、隔 15 秒以上回到页面、或者下拉刷新，就能看到。
- 两个人同时改同一道菜时，后保存的人会被问「要不要覆盖」，不会悄悄把对方的改动盖掉。
- 菜篮和买菜清单也是共用的：一个人点了菜，另一个人也能看到；买菜时买到一样勾一样，两边同步。
- 家里的库存、想吃清单也是共用的。买菜清单会自动对比库存，家里有的不提醒买。
- 做菜记录也是共用的，打卡时可以写「掌勺」是谁。

## 怎么运行

用微信开发者工具打开本目录（`D:\project\Xiaoliang_Kitchen`），点「编译」。第一次打开菜单是空的，可以点「放几道示例菜」看效果，以后在「我的」里一键删掉。

注意：开发者工具和手机上的体验版用的是同一个云环境，在开发者工具里增删的就是自己的真实数据。

## 数据存在哪

- 云数据库（两个人共用）：
  - `categories` 分类
  - `dishes` 菜品，原料和步骤都在里面
  - `plans` 几条共用记录：`current` 菜篮和买菜清单、`pantry` 库存、`wishes` 想吃清单
  - `cook_logs` 做菜记录
- 云存储：`covers/` 成品照大图、`thumbs/` 小图（列表用，省流量）、`steps/` 步骤照片、`logs/` 打卡照片、`wishes/` 想吃清单的照片
- 「做过几次」「上次做」不单独存，按做菜记录算，跟记录页永远对得上
- 手机本地：云上数据的缓存（打开时先显示，没网也能看）
- 想留一份备份：「我的 → 备份与导入 → 备份到微信」生成一个文件，发到微信聊天里、在电脑版微信里直接存到电脑，或者（不带照片时）复制成文字存到备忘录；要导回来用「从文件导入」，可以从聊天里选文件，也可以粘贴复制的内容
- 一次加好几道新菜：「我的 → 备份与导入 → 把模板发到微信」，或者直接用 `docs/菜谱导入模板.json`，照着改。字段是中文的：菜名、分类、主料（一项写一样，比如「土豆 2个」）、做法（要计时的步骤写「8分钟」）等，里面有说明。改好发到微信聊天里，在「我的 → 数据导入」选这个文件。照片导入以后在菜的编辑页里加
