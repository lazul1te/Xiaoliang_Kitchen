# 拿手菜小本本

好好做饭，也好好记录。

一个两个人一起记的菜谱小程序：像翻餐厅菜单一样挑今天要做的菜，每道菜记下原料和详细做法；做的时候一步一步看、带计时，做完打个卡。能打开这个小程序的人（管理员和体验成员）共用一本菜谱，都能看、都能改。原生小程序（JavaScript）+ 微信云开发（免费环境）。只用体验版，不发布上线。

## 第一次运行前

1. **建数据库集合**：开发者工具顶部点「云开发」打开控制台 → 数据库，新建四个集合 `categories`、`dishes`、`plans`、`cook_logs`。
2. **把权限设成两个人共用**：四个集合都打开权限设置，选「自定义安全规则」，把输入框里原来的内容全部删掉，换成：
   ```json
   {
     "read": "auth.openid != null",
     "write": "auth.openid != null"
   }
   ```
   意思是用微信打开这个小程序的人都能读写（体验版只有体验成员能打开）。`{ "read": true, "write": true }` 控制台会报 rule invalid，不能用。
   也不要选「仅创建者可读写」或「所有用户可读，仅创建者可写」：前者看不到对方的菜，后者改不了对方加的菜。
3. **填环境 ID**（建议）：控制台里复制环境 ID，填进 `miniprogram/config.js`。不填的话会用账号下第一个创建的环境。
4. **隐私保护指引**：小程序后台 → 设置 → 服务内容声明 → 用户隐私保护指引，声明「选中的照片或视频信息」，用途写「给菜品、做菜步骤和做菜记录添加照片」。不填的话选不了照片。
5. **加体验成员**：小程序后台 → 成员管理 → 体验成员，用微信号把对方加进来（个人小程序最多 15 人）。

## 发体验版（给手机上用）

1. 开发者工具右上角点「上传」，版本号写 `1.0.0` 这样的，备注随便写。
2. 打开小程序后台 → 管理 → 版本管理，在「开发版本」里把刚上传的版本「选为体验版」，就能看到体验版二维码。
3. 两个人用微信扫这个二维码打开；以后在微信下拉的「最近使用」里就能找到。
4. 以后每次改完代码，重复 1、2 两步，重新打开小程序就是新版本。
5. **千万别点「提交审核」或「发布」**：发布后免费云环境会在上线第 15 天到期，之后要付费。

## 两个人一起用

- 一方改了，另一方重新打开小程序、隔 15 秒以上回到页面、或者下拉刷新，就能看到。
- 两个人同时改同一道菜时，后保存的人会被问「要不要覆盖」，不会悄悄把对方的改动盖掉。
- 今日菜单和买菜清单也是共用的：一个人点了菜，另一个人也能看到；买菜时买到一样勾一样，两边同步。
- 做菜记录也是共用的，打卡时可以写「掌勺」是谁。

## 怎么运行

用微信开发者工具打开本目录（`D:\project\Xiaoliang_Kitchen`），点「编译」。第一次打开菜单是空的，可以点「放几道示例菜」看效果，以后在「我的」里一键删掉。

注意：开发者工具和手机上的体验版用的是同一个云环境，在开发者工具里增删的就是自己的真实数据。

## 数据存在哪

- 云数据库（两个人共用）：
  - `categories` 分类
  - `dishes` 菜品，原料和步骤都在里面
  - `plans` 今日菜单和买菜清单，只有一条记录
  - `cook_logs` 做菜记录
- 云存储：`covers/` 成品照大图、`thumbs/` 小图（列表用，省流量）、`steps/` 步骤照片、`logs/` 打卡照片
- 手机本地：云上数据的缓存（打开时先显示，没网也能看）
- 想留一份备份：「我的 → 数据导出」生成一个文件发到微信聊天里
